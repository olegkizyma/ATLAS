# 🎯 ATLAS Режим Прослуховування та Зір - Інструкція користувача

## 📋 Огляд функціональності

ATLAS тепер підтримує два режими взаємодії з мікрофоном:

### 🎤 **Режим 1: Швидкий запис (Одиночний клік)**
- **Дія**: Клік по кнопці мікрофона
- **Результат**: Запуск запису через Whisper Large 3
- **Призначення**: Швидке введення команд та питань
- **Візуальний індикатор**: 🔴 Записую

### 👁️ **Режим 2: Atlas + Зір (Утримання 1.5 сек)**
- **Дія**: Утримання кнопки мікрофона 1.5 секунди
- **Результат**: Активація режиму прослуховування + система зору
- **Призначення**: Безперервне прослуховування гарячого слова "Атлас" + аналіз зображення
- **Візуальний індикатор**: 👁️ Атлас+ з помаранчевим пульсуючим індикатором

## 🔥 Гаряче слово "Атлас"

Система реагує на такі варіанти:
- **"Атлас"** (основний варіант)
- **"Аталс"** (для неточної вимови)
- **"Атласе"** (звертальна форма)
- **"Atlas"** (англійська версія)

### 📝 Приклади використання:

#### 1. Пряма команда:
```
"Атлас, яка погода сьогодні?"
```
Система одразу обробить команду після слова "Атлас".

#### 2. Привітання + команда:
```
"Привіт, Атлас, розкажи про штучний інтелект"
```
Система вирізає команду після звернення.

#### 3. Звичайне звернення:
```
"Атлас"
```
Система відповість підтвердженням і перейде в режим запису.

## 📹 Система зору

### Активація:
- Утримання кнопки мікрофона 1.5 секунди
- Автоматичний запит доступу до камери
- Запуск Grisha screen monitoring

### Можливості:
- **Аналіз зображення з камери**: Захоплення кадрів з веб-камери
- **Моніторинг екрану**: Відстеження дій на екрані
- **Візуальний контекст**: Надання додаткової інформації для AI

### Вимкнення:
- Повторне утримання кнопки 1.5 секунди
- Автоматичне вимкнення камери та очищення ресурсів

## 🔧 Технічні характеристики

### Whisper Large 3:
- **Beam sizes**: 1, 3, 5, 10 (адаптивний вибір)
- **Мови**: Українська, Англійська, Російська
- **Якість**: Висока точність розпізнавання

### Система зору:
- **Модулі**: MediaPipe, OpenCV, Pillow, YOLO
- **Формати**: Підтримка основних форматів зображень
- **Інтеграція**: Повна інтеграція з Goose Vision

### Cross-Platform підтримка:
- **Desktop**: Підтримка mouse events
- **Mobile**: Підтримка touch events з тактильним відгуком (вібрація)
- **Responsive**: Адаптивний дизайн для всіх пристроїв

## 🚀 Приклади використання

### Сценарій 1: Швидке питання
1. Клік по мікрофону
2. Дочекайтеся червоного індикатора
3. Скажіть ваше питання
4. Система автоматично обробить запит

### Сценарій 2: Безперервна робота з зором
1. Утримуйте мікрофон 1.5 сек
2. Надайте доступ до камери
3. Чекайте помаранчевий індикатор
4. Скажіть "Атлас" + ваша команда
5. Система буде аналізувати зображення та слухати команди

### Сценарій 3: Складна команда з контекстом
1. Активуйте режим "Атлас + Зір"
2. Скажіть: "Атлас, що ти бачиш на екрані?"
3. Система проаналізує зображення та дасть відповідь
4. Продовжуйте діалог без додаткової активації

## ⚠️ Важливі зауваження

### Приватність:
- Камера використовується тільки коли активний режим зору
- Всі ресурси автоматично звільняються при вимкненні
- Локальна обробка зображень (без передачі в хмару)

### Продуктивність:
- Система автоматично вибирає оптимальні налаштування
- Адаптивний beam size для різних типів запитів
- Ефективне використання пам'яті та процесора

### Сумісність:
- Потрібен сучасний браузер з підтримкою Web Speech API
- Рекомендується Chrome/Edge для найкращої продуктивності
- WebRTC підтримка для доступу до камери

## 📊 Діагностика проблем

### Мікрофон не працює:
1. Перевірте дозволи браузера на мікрофон
2. Перевірте що мікрофон не зайнятий іншими програмами
3. Спробуйте перезавантажити сторінку

### Камера недоступна:
1. Надайте дозвіл на камеру в браузері
2. Перевірте що камера не використовується іншими програмами
3. Перевірте налаштування приватності системи

### Гаряче слово не реагує:
1. Переконайтеся що активний режим прослуховування (жовтий/помаранчевий індикатор)
2. Говоріть чітко та достатньо голосно
3. Використовуйте один із підтримуваних варіантів ("Атлас", "Atlas")

## 🎯 Поради для ефективного використання

1. **Для швидких запитань**: Використовуйте одиночний клік
2. **Для складних завдань**: Активуйте режим зору для додаткового контексту
3. **Для безперервної роботи**: Залишайте режим прослуховування активним
4. **Для точності**: Говоріть чітко після активації гарячого слова
5. **Для приватності**: Вимикайте режим зору коли не потрібен
