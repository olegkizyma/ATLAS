ATLAS Architecture

Інтелектуальна Multi-Agent система з Recovery Bridge, розумною пам'яттю та візуальним моніторингом

Оновлено 8 вересня 2025

Поточний стан системи

Усі сервіси активні та працюють в штатному режимі. Recovery Bridge система успішно інтегрована та функціонує.

Frontend - порт 5001
Orchestrator - порт 5101
Recovery Bridge - порт 5102
Ukrainian TTS - порт 3001
Goose Web - порт 3000
Vision API - інтегровано

Легенда & Ключові компоненти

Агенти Atlas (планувальник), Grisha (валідатор), Tetyana (виконавець)
Recovery Bridge WebSocket (:5102) + Health (:5103) - автоматичне відновлення після помилок
Probe Cycle Мінімальний експеримент для збирання відсутніх артефактів
Memory System SQLite факти з exponential decay + frequency ранжуванням
Semantic Search Hash/remote embeddings з cosine similarity top-K
Vision System OpenCV + YOLO + MediaPipe для обробки зображень
