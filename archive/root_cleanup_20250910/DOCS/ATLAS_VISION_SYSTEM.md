# ATLAS Vision System Documentation

## Огляд

ATLAS Vision System - це інтегрована система комп'ютерного зору для автоматичного парсингу фото з покращенням та візуальною передачею послідовності дій як на відео.

## Функціональність

### 🔍 Автоматичний аналіз зображень
- **Детекція об'єктів** - YOLO v8 для розпізнавання предметів
- **Розпізнавання облич** - MediaPipe Face Detection
- **Відстеження рук** - MediaPipe Hands для жестів
- **Аналіз поз** - MediaPipe Pose для людей
- **Опис сцени** - Автоматичне генерування опису

### 🎨 Покращення зображень
- **Автоматична корекція** - Контраст, чіткість, кольори
- **Зменшення шуму** - Фільтрація та згладжування
- **Оптимізація якості** - Smart enhancement алгоритми

### 🎬 Генерація відео-послідовностей
- **Покрокова візуалізація** - Анімована демонстрація аналізу
- **Візуальні ефекти** - Підсвічування, сітки, індикатори
- **Часові послідовності** - Timing-based анімації
- **Експорт MP4** - Готові відео файли

## API Endpoints

### Статус системи
```
GET /api/vision/status
```
Повертає інформацію про доступність vision модулів.

### Завантаження та базовий аналіз
```
POST /api/vision/upload
Content-Type: application/json

{
  "image": "data:image/jpeg;base64,..."
}
```

### Детальний аналіз з відео
```
POST /api/vision/analyze
Content-Type: application/json

{
  "image": "data:image/jpeg;base64,...",
  "generate_video": true
}
```

### Покращення зображення
```
POST /api/vision/enhance
Content-Type: application/json

{
  "image": "data:image/jpeg;base64,..."
}
```

### Отримання відео послідовності
```
GET /api/vision/sequence/<timestamp>
```

### Очищення тимчасових файлів
```
POST /api/vision/cleanup
Content-Type: application/json

{
  "hours": 24
}
```

## Використання Frontend

### Автоматична ініціалізація
Vision система автоматично ініціалізується при завантаженні сторінки та створює UI панель.

### Інтерфейс користувача
- **Drag & Drop зона** - Перетягування зображень
- **Прев'ю панель** - Оригінал та покращена версія
- **Аналіз панель** - Результати детекції
- **Відео панель** - Генеровані послідовності

### Програмний доступ
```javascript
// Перевірка доступності
if (window.atlasVision && window.atlasVision.isVisionAvailable()) {
    // Отримання поточного аналізу
    const analysis = window.atlasVision.getCurrentAnalysis();
    
    // Отримання послідовності дій
    const sequence = window.atlasVision.getCurrentSequence();
}
```

## Типи послідовностей дій

### 1. Face Detection (Розпізнавання облич)
- **Тривалість**: 2.0 секунди
- **Ефект**: Пульсуючий зелений контур
- **Призначення**: Виявлення та підрахунок облич

### 2. Hand Tracking (Відстеження рук)
- **Тривалість**: 3.0 секунди  
- **Ефект**: Рухомі жовті лінії
- **Призначення**: Аналіз жестів та позицій рук

### 3. Pose Analysis (Аналіз поз)
- **Тривалість**: 2.5 секунди
- **Ефект**: Червона сітка з анімацією
- **Призначення**: Детекція поз та рухів людей

### 4. Object Recognition (Розпізнавання об'єктів)
- **Тривалість**: 1.5 секунди
- **Ефект**: Фокусні кола з центру
- **Призначення**: Ідентифікація предметів

### 5. Scene Understanding (Розуміння сцени)
- **Тривалість**: 1.0 секунда
- **Ефект**: Завершальний fade effect
- **Призначення**: Загальний аналіз контексту

- **Максимальний розмір**: 10MB на зображення

- **CPU**: Підтримка AVX2 для OpenCV
- **Простір**: 100MB для тимчасових файлів

## Інтеграція з ATLAS агентами

### Tetyana (Executor)
- Може використовувати vision для аналізу зображень в завданнях
- Автоматично викликає vision API при отриманні зображень
- Інтегрує результати аналізу в відповіді

### Atlas (Planner)
- Використовує vision аналіз для планування задач
- Враховує візуальний контекст при створенні планів

### Grisha (Validator)
- Перевіряє корректність vision аналізу
- Валідує результати детекції

## Моніторинг та логування

### Метрики Prometheus
- `vision_requests_total` - Загальна кількість запитів
- `vision_processing_duration_seconds` - Час обробки
- `vision_errors_total` - Кількість помилок
- `vision_models_loaded` - Статус завантажених моделей

### Логування
- Всі vision операції логуються з UTC+offset форматом
- Включає деталі про використані моделі та результати
- Інтеграція з основною системою логування ATLAS

## Безпека та обмеження

### Обмеження розміру файлів
- Максимум 10MB на зображення

- Автоматичне очищення через 24 години

- Унікальні імена файлів з timestamp

### Продуктивність
- Асинхронна обробка для великих зображень
- Кешування результатів аналізу
- Оптимізація моделей для швидкості
