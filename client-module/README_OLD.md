# GitHub Models Client Module

Готовый модуль для интеграции GitHub Models Proxy в ваши проекты.

## � Последние изменения

**✅ Обновлено для работы только через прокси:**
- Убрана альтернатива прямого подключения к GitHub API
- Клиенты работают только через ваш прокси сервер
- Добавлена защита от 429 ошибок (Rate Limiting)

**🛡️ Защита от Rate Limiting:**
- **Автоматические повторы** при ошибках (429, 5xx, timeout)
- **Экспоненциальная задержка** с джиттером между попытками
- **Настраиваемые задержки** между запросами при массовом тестировании
- **Умные повторы** только для временных ошибок

## �📋 Структура модуля

- `python_client/` - Python клиент с поддержкой всех 58 моделей + retry
- `nodejs_client/` - Node.js клиент с поддержкой всех 58 моделей + retry
- `models.json` - Полный список всех доступных моделей
- `README.md` - Документация по использованию

## 🚀 Быстрый старт

### Python
```bash
cd python_client
pip install -r requirements.txt
python client.py
```

### Node.js
```bash
cd nodejs_client
npm install
node client.js
```

## 🎯 Особенности

- ✅ Поддержка всех 58 моделей GitHub Models
- ✅ **Только через прокси** - никакого прямого подключения к GitHub
- ✅ **Защита от 429** - автоматические повторы и задержки
- ✅ **Настраиваемые retry** - количество попыток и задержки
- ✅ Готовый для интеграции код
- ✅ Обработка ошибок с детальными сообщениями
- ✅ Фильтрация моделей по провайдеру и типу
- ✅ Статистика использования токенов
- ✅ Безопасность через прокси без раскрытия GitHub токена
